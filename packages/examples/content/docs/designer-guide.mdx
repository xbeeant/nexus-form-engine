## 概述

`@xbeeant/form-engine-designer` 是 form-engine 的可视化 Schema 设计器，提供：

- **Palette（组件面板）** — 拖拽 widget / layout 到画布
- **Canvas（画布）** — 可视化渲染 + 拖放目标
- **PropertyPanel（属性面板）** — 编辑选中节点属性（bind / 校验 / 联动 / 枚举 / 表达式等）
- **三种模式** — design（设计）/ preview（预览）/ schema（JSON 编辑）
- **Undo / Redo** — 基于 SchemaHistory，支持 Cmd+Z / Cmd+Shift+Z

## 安装

```bash
npm install @xbeeant/form-engine-designer @xbeeant/form-engine @xbeeant/form-engine-ui
```

peerDependencies：`antd >= 5`、`react >= 18`、`react-dom >= 18`、`dayjs >= 1.11`。

## 最小用法

```tsx
import { Designer } from '@xbeeant/form-engine-designer';
import type { NexusSchema } from '@xbeeant/form-engine';

const initialSchema: NexusSchema = {
  type: 'object',
  properties: {
    username: {
      type: 'string',
      widget: 'input',
      title: '用户名',
      required: true,
    },
  },
};

function App() {
  return (
    <Designer
      schema={initialSchema}
      onSchemaChange={(schema) => console.log('新 Schema', schema)}
    />
  );
}
```

`<Designer>` 默认使用 `@xbeeant/form-engine-ui` 的 `registerAntdUI` 注册控件、`widgetSchemas` 提供属性描述符，开箱即用。

## Designer Props

| Prop | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `schema` | `NexusSchema` | `{type:'object',properties:{}}` | 初始表单 Schema |
| `onSchemaChange` | `(schema: NexusSchema) => void` | — | 每次 schema 变更时回调 |
| `propertySchemaMap` | `PropertySchemaMap` | `widgetSchemas` | widget 名 → 属性描述符映射 |
| `registerUI` | `(engine: NexusEngine) => void` | `registerAntdUI` | UI 注册函数，可接入自定义 UI 库 |
| `fields` | `FieldDef[]` | — | 外部字段列表，传入后 palette 多一个「字段列表」分组 |
| `widgetCatalog` | `CatalogItem[]` | — | 额外 widget 目录项，同名覆盖内置 |
| `layoutCatalog` | `CatalogItem[]` | — | 额外 layout 目录项，同名覆盖内置 |

## 模式切换

Designer 内部提供三种模式，通过 `useDesigner()` 访问：

| 模式 | 说明 |
| :--- | :--- |
| `'design'` | 默认模式，显示 3 面板布局（Palette + Canvas + PropertyPanel） |
| `'preview'` | 仅渲染表单预览 |
| `'schema'` | 原始 JSON 编辑器，可直接粘贴 / 编辑 JSON |

```tsx
import { useDesigner } from '@xbeeant/form-engine-designer';

function CustomToolbar() {
  const { mode, setMode } = useDesigner();
  // mode: 'design' | 'preview' | 'schema'
}
```

## 扩展 Catalog

Designer 内置 38 个 widget 目录项（input / select / number / textarea / switch ...）和 12 个 layout 目录项（card / tabs / grid / flex ...）。通过 `widgetCatalog` / `layoutCatalog` 可自定义扩展：

```tsx
import { Designer } from '@xbeeant/form-engine-designer';
import type { CatalogItem } from '@xbeeant/form-engine-designer';

const customCatalog: CatalogItem[] = [
  {
    label: '富文本',
    icon: '✍️',
    category: 'widget',
    widget: 'richText',
    createNode: () => ({
      type: 'string',
      widget: 'richText',
      title: '富文本',
    }),
  },
];

function App() {
  return (
    <Designer
      schema={mySchema}
      widgetCatalog={customCatalog}
    />
  );
}
```

同名 widget 的目录项会覆盖内置项。

## 外部字段列表

传入 `fields` 后，palette 会出现「字段列表」分组，支持拖拽外部字段到表单：

```tsx
import type { FieldDef } from '@xbeeant/form-engine-designer';

const externalFields: FieldDef[] = [
  { id: 'order_no', name: '订单编号', widget: 'input' },
  { id: 'amount', name: '金额', widget: 'number' },
  { id: 'status', name: '订单状态', widget: 'select' },
  { id: 'created_at', name: '创建时间', widget: 'date' },
];

<Designer schema={schema} fields={externalFields} />
```

## useDesigner() API

通过 `useDesigner()` 可访问设计器上下文的全部状态与方法：

```tsx
import { useDesigner } from '@xbeeant/form-engine-designer';

function CustomPanel() {
  const {
    // Schema 状态
    schema,
    setSchema,

    // 节点选择
    selectedPath,
    selectNode,

    // 模式
    mode,
    setMode,

    // Schema 操作
    addNode,     // (parentPath, key, node) => void
    removeNode,  // (path) => void
    updateNode,  // (path, patch) => void
    moveNode,    // (from, to) => void
    renameNode,  // (path, newKey) => void

    // Undo / Redo
    undo,
    redo,
    canUndo,
    canRedo,

    // 配置项
    registerUI,
    fields,
    widgetCatalog,
    layoutCatalog,
    propertySchemaMap,
  } = useDesigner();
}
```

## 导入 / 导出

Designer 工具栏内置 Import / Export 按钮：

- **Import** — 从 JSON 文件导入 Schema
- **Export** — 将当前 Schema 导出为 JSON 文件
- **Clear** — 清空画布，恢复为空的 Schema 结构

也可通过 `setSchema` 程序化设置：

```tsx
function ImportButton() {
  const { setSchema } = useDesigner();

  return (
    <button
      onClick={() => {
        const json = JSON.parse(fileContent);
        setSchema(json);
      }}
    >
      导入 Schema
    </button>
  );
}
```

## schemaUtils

包内导出 Schema 操作工具函数，可在自定义面板中直接操作 Schema 结构：

```tsx
import {
  addChildToSchema,
  removeNodeFromSchema,
  updateNodeInSchema,
  getNodeAtProperties,
  collectDataFieldPaths,
} from '@xbeeant/form-engine-designer';

// 向某个路径添加子节点
addChildToSchema(schema, 'basic', {
  type: 'string',
  widget: 'input',
  title: '新字段',
});

// 收集所有数据字段路径
const paths = collectDataFieldPaths(schema);
```

## 自定义 UI 注册

`<Designer>` 的 `registerUI` 参数默认为 `registerAntdUI`。如果需要接入其他 UI 库，可传入自定义函数：

```tsx
import { registerMyUI } from '@my-ui-kit';

<Designer
  schema={schema}
  registerUI={registerMyUI}
/>
```

自定义 `registerUI` 应调用 `engine.registerWidgets()` 和 `engine.registerLayouts()` 注册对应的 widget 和 layout 组件。

## 属性面板编辑器

Designer 内置多种属性编辑器，通过 `propertySchemaMap` 定义各 widget 的属性结构：

| 编辑器 | 功能 |
| :--- | :--- |
| `bindEditorWidget` | 数据绑定路径编辑 |
| `defaultEditorWidget` | 默认值编辑 |
| `validateEditorWidget` | 校验规则编辑 |
| `dependenciesEditorWidget` | 联动依赖编辑 |
| `reactionsEditorWidget` | 结构化联动表达式编辑 |
| `enumEditorWidget` | 枚举数据编辑 |
| `optionsEditorWidget` | 下拉选项编辑 |
| `codeEditorWidget` | 代码/表达式编辑 |
| `remoteDataEditorWidget` | 远程数据配置 |

## 布局容器

Designer 内置以下布局容器，拖入画布后可嵌套字段：

| 容器 | 说明 |
| :--- | :--- |
| `card` | 卡片容器 |
| `grid` | 栅格布局（column 属性分列） |
| `tabs` + `tabPane` | 标签页 |
| `collapse` + `collapsePanel` | 手风琴折叠面板 |
| `steps` + `step` | 步骤条 |
| `flex` | Flex 布局 |
| `space` | 间距布局 |
| `divider` | 分割线 |
| `void` | 无渲染容器（字段直接平铺） |
| `passThrough` | 透传容器 |

> 布局容器的 Key 不会进入 `formData` 数据路径，可以放心调整布局结构。
